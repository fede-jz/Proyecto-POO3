# Proyecto-POO3

Repositorio para el proyecto de Programación Orientada a Objetos (POO).

## 📁 Estructura del Proyecto

```text
Proyecto-POO3/
├── src/           # Código fuente del proyecto
├── docs/          # Documentación y diagramas UML
├── tests/         # Pruebas unitarias y de integración
├── .gitignore     # Archivos ignorados por Git
└── README.md      # Descripción del proyecto
```

## 🚀 Inicio Rápido

1. Clonar el repositorio:
   ```bash
   git clone <URL_DEL_REPOSITORIO>
   ```
2. Navegar a la carpeta del proyecto:
   ```bash
   cd Proyecto-POO3
   ```

## 📝 Descripción y Objetivos

- Implementación de conceptos de POO: Encapsulamiento, Herencia, Polimorfismo y Abstracción.
- Buenas prácticas de diseño y arquitectura de software.
